# 🔗 URL Shortener API 🚀

A modern full-stack URL Shortener built with **FastAPI + React + MongoDB**, featuring authentication, analytics, and custom short links.

## ✨ Features

- 🔗 Shorten long URLs instantly
- ✏️ Custom short codes
- 📊 Advanced analytics (clicks, device, country tracking)
- ⏳ Expiry-based links
- 🔐 User authentication (Login/Register)
- 📱 Responsive UI (Mobile + Desktop)

---

## 🛠 Tech Stack

### Backend

- FastAPI
- MongoDB
- Python

### Frontend

- React (Vite)
- Axios
- React Router
- React Hot Toast

## 📌 API Endpoints

### 🔹 Create Short URL

### 🔹 Redirect URL

GET /{short_code}

### 🔹 Get Analytics

GET /analytics/{short_code}
